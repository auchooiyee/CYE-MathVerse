Digits obey the base.

In base b, allowed digits are 0 to b − 1. In base five: 0, 1, 2, 3, 4. Never write a digit 5 in base five.

Field guide

Same value. New code.

In 101₂, the places are 4, 2 and 1. So 101₂ = 5₁₀. To convert 5₁₀ back to binary, divide by 2 repeatedly and read the remainders upwards: 101₂.

In base eight, the places are 64, 8 and 1. Thus 17₈ = 1 × 8 + 7 = 15₁₀. Only digits 0–7 are valid in base eight.

To convert between two non-decimal bases, go via base ten. Place value is bⁿ; digit value is digit × bⁿ.
