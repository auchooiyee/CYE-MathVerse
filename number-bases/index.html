FIELD GUIDE

Same value. New code.

In $101_2$, the place values are $4, 2,$ and $1$. So $101_2 = 4 + 0 + 1 = 5_{10}$. To convert $5_{10}$ back to binary, divide by $2$ repeatedly and read the remainders upwards: $101_2$.

In Base $8$, the place values are $64, 8,$ and $1$. Thus $17_8 = (1 \times 8) + 7 = 15_{10}$. Only digits $0$–$7$ are valid in Base $8$.

To convert between two non-decimal bases, use Base $10$ as your bridge: $\text{Place Value} = b^n$ and $\text{Digit Value} = \text{digit} \times b^n$.
