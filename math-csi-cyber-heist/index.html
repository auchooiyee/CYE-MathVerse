FORM 4 MATHEMATICS FORMULA CODEX

Official KSSM Mathematics Quick Reference

Chapter 2: Number Bases (Asas Nombor)

• Base 2: Place values 2⁰=1, 2¹=2, 2²=4, 2³=8, 2⁴=16, ...

• Base 8: Place values 8⁰=1, 8¹=8, 8²=64, 8³=512, ...

• Base 5: Place values 5⁰=1, 5¹=5, 5²=25, 5³=125, ...

Chapter 3: Logical Reasoning (Penakulan Logik)

• "p and q" is TRUE only if both p and q are true.

• "p or q" is TRUE if at least one component is true.

• Deductive Form I: All A are B. C is A. ∴ C is B.

• Deductive Form II: If p, then q. p is true. ∴ q is true.

• Deductive Form III: If p, then q. Not q is true (~q). ∴ Not p is true (~p).

Chapter 4: Operations on Sets (Operasi Set)

• Intersection (A ∩ B): Elements common to both A and B.

• Union (A ∪ B): All elements in A, B, or both.

• Complement (A'): Elements in Universal Set ξ that are NOT in A.

Chapter 5: Network in Graph Theory (Teori Graf)

• Sum of degrees of vertices: ∑d(v) = 2E (where E is the number of edges).

• Tree criteria: Simple connected graph with E = V − 1 edges.

Chapter 7: Graphs of Motion (Graf Gerakan)

• Speed-Time Graph Gradient: Acceleration a = (v − u) / t.

• Area Under Speed-Time Graph: Total Distance traveled.

Chapter 8: Measures of Dispersion (Sukatan Serakan)

• Interquartile Range: IQR = Q₃ − Q₁.

• Outlier Rule: Values < Q₁ − 1.5(IQR) or > Q₃ + 1.5(IQR).

Chapter 9: Probability of Combined Events

• Independent Events: P(A ∩ B) = P(A) × P(B).

• Addition Rule: P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
