Chapter 1: Quadratic Functions & Equations

• Standard Form: ax² + bx + c = 0

• Axis of Symmetry: x = −b / (2a)

• Peak / Minimum Coordinate: Maximum or minimum point occurs at vertex x = −b / (2a).

Chapter 2: Number Bases

• Binary (Base 2): Place values 1, 2, 4, 8, 16, 32, 64...

• Octal (Base 8): Place values 1, 8, 64, 512...

• Base 5: Place values 1, 5, 25, 125...

Chapter 6: Linear Inequalities in Two Variables

• Region above line: y > mx + c (dashed) or y ≥ mx + c (solid)

• Region below line: y < mx + c (dashed) or y ≤ mx + c (solid)

Chapter 7: Graphs of Motion

• Speed-Time Gradient: Acceleration a = (v − u) / t

• Area Under Speed-Time Graph: Total Distance Traveled (Trapezium = ½(a + b)h)

Chapter 5: Network in Graph Theory

• Sum of Degrees: ∑d(v) = 2E

• Minimum Spanning Tree: Connected graph with E = V − 1 edges and no cycles.

Chapter 9: Probability of Combined Events

• Independent Events: P(A ∩ B) = P(A) × P(B)

• Union of Events: P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
